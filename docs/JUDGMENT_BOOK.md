# 判断簿

判断簿是账号范围的可选扩展入口。数据保存在主 SQLite 的独立 `judgment_*` 表和 `judgments` 表；每条记录绑定已有的服务器文件夹项目。所有 Agent 工作仍使用该项目的普通会话、Job 和持久队列。

## 使用

在功能选择中开启判断簿，或从扩展功能区打开。默认关闭，由每个账号自行开启。关闭显示不取消计划。

- **预测**：填写题意、本人概率、事件截止与明确判据。保存后概率变化追加版本和理由。事件截止后不能回改事前概率；修改题意、期限或数值规则会建立关联新题。
- **长期想法**：保存理由、疑点与回顾时间。本人选择维持、修正或搁置，可再次安排回顾；不参与预测评分。
- **讨论**：从详情打开所属项目的普通会话草稿，发送才执行。正常会话中的 `codex_web_judgments` 工具先调用 `context` 获取完整操作契约。旧线程可使用环境提供的 `CODEX_WEB_JUDGMENT_CLI`，不要读取或展示任务凭据。
- **复盘与导出**：列表优先待反馈、到期待核验、待证据，然后按日期排列。支持项目、主题、状态与内容筛选。完整 JSON 导出包含原始快照、概率版本、证据、结论、更正、执行计划和时间线。

## 核验与结果

事件截止与检查时间分别保存，默认检查一次。`Recurrence.kind=once` 持久保存绝对日期，不受会话内等待接口的 365 天上限影响。调度复用原来的 `processDueWakePlans` 和 `RecurringStore.fire`，没有新的轮询器或隐藏模型执行器。

到期时在同一数据库事务中标记检查并创建普通项目会话和待发送项。一次性任务完成触发后不再计算下一次；`recurring_runs` 的唯一键和事务保证重启/重复扫描不会重复建会话。项目归档或账号停用时不触发；服务器项目身份变化会阻止检查。恢复项目后仍有效的到期计划可执行一次。

私人信息与长期想法到期直接进入“待我反馈”，不创建模型任务。公开事实由 Agent 保存来源和核心摘录后提交候选，本人通过页面确认。证据不足或冲突时保持待证据，不能把未找到证据或未回应当成不成立。

结构化数值需要精确匹配事先保存的来源 URL、时期、单位和比较规则。服务端自己计算 `gt/gte/lt/lte/eq`，不采用 Agent 声称的数值结论。仅事先允许自动揭晓且证据完整、一致时自动出结果；未授权时仍等待本人确认。历史中的冲突证据不会因选择另一条证据而被忽略，无法消除的冲突可由本人追加明确反馈。

股票模板保存代码、市场、币种、基准日期/值、目标日期、交易所时区、收盘或盘中、原始/复权/含分红以及缺数、非交易日、停牌和公司行动政策。自动股票结论额外要求实际交易日、停牌与公司行动核查和调整口径一致；采用此前交易日时还须核实目标日确属非交易日、所取日期确为最近交易日，不能任取旧价格。第一版盘中口径走人工，不自动猜测取样时点。这里提供指定公开/已授权来源的 Agent 查证工作流，不提供全市场行情订阅，不内置 IBM 演示源，不保存 URL 中的 API 密钥，也不交易或购买数据。

## 持久性与权限

- 正常网页接口使用已有登录、账号隔离和 CSRF 保护。Agent 接口使用当前运行 Job 的短期凭据；可浏览本人其他项目的判断，但写入必须在该记录所属的服务器项目。
- 所有写操作使用请求键去重，改变同一请求的载荷返回冲突。更新校验当前记录版本；原题、首条概率和判据没有原地编辑入口。
- 到期核验绑定检查编号和会话。取消、改期或提交后，旧检查不能再次写回；取消会删除该检查尚未派发的原始待发送项，不删除用户后续输入。已经运行的会话可能仍结束其当前执行，但不能提交旧检查结果，可从该会话的停止按钮结束执行。
- 计划状态、真实 Job 状态和判断结果分别显示。失败不自动重排无限重试，用户可以设下一次检查。隐藏入口不停止调度。
- 结论更正追加结果并引用前一结果；后续研究仍可追加证据，原结论和原证据保留。应用层追加保护不宣称能防止 root 直接修改数据库。
- 核心摘录、数值和口径保存在业务表，不依赖来源会话是否存在。可引用同项目已保存消息的附件；附件继续使用原有受管存储和冷存储。引用会保护源会话不被永久删除；归档和冷存储仍可用。已经删除或移动的无附件来源会话不会再显示失效跳转按钮。

## 得分

可判定预测的二元 Brier 为 `(p-y)²`，范围 0–1。首条和最后一个有效事前概率分别汇总，一题只计一次，以当前确认结果为准。无法判定、撤回、长期想法及标记为练习/验收的记录不计分；同时显示样本量、未决和撤回数量。少量样本不代表预测能力提升。

## 验证

`tests/judgments.test.ts` 覆盖事务回滚、重开数据库、超过 365 天、重复触发、私有反馈无 Job、版本冲突、不可回改概率、候选确认、确定计算、缺失/冲突、股票口径、取消后回写、失败重试、账号/项目隔离、草稿、附件保留和更正。既有周期任务与显示偏好测试继续适用。

部署者应使用独立合成项目验证普通任务、到期检查、工具、存证和页面确认；桌面及手机视口不代替实体设备验收。
